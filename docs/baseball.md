# ダイヤモンドループ

青葉高校野球部の監督となり、練習カードで選手を育て、夏の全国優勝を目指す高校野球ローグライト。登録不要で、スマホの縦画面とデスクトップに対応しています。

[ブラウザで遊ぶ](https://lurmaru.github.io/diamond-loop-baseball/baseball.html)

## 遊び方

1. 最初の春は、9人の新入生を1枚ずつ開封します。カードの縁と記号が選手ランク（C・B・A・S・SS・Z）を表し、S以上は天才です。全員が入部し、最後に重点育成する1人を選びます。
2. 創部時は共通の練習デッキ12枚でそのまま練習開始。初期手札はシャッフルして引く4枚です。使った位置にだけ次の札が補充され、残りは持ち越します。山札が空になると捨て札を混ぜ直します。
3. 1年は4月1日から3月31日までの365日。1枚で1〜3日進み、到着日のマスに立ち寄ります。手札には成長の目安、編成画面には1日あたりの基礎練習点を表示。2日連続なら1日あたり15%、3日連続なら30%多く練習点が入ります。行事による途中停止は実際の日数で計算します。おまかせ練習は最長14日進み、行事・寄り道・希少な発見で止まります。
4. 6月と12月の合宿では手札1枚を使い、表示された選手と特殊能力について1回抽選します。基本習得率は40%、直伝札なら65%。地域の練習会では到着に使った札で10%、直伝札なら20%です。通常練習の覚醒では能力値が伸びます。
5. 合宿でひらめきが起きると、年1回までカード1枚を永久進化できます。指定系統の次に使うと練習点 +2。卒業生が学校を再訪したときは、現役時の得意分野の札を選んで直伝を残せます。
6. 夏の大会が終わるとデッキを組み換えられます。創部以来初めて札を選べるのはこのタイミングです。以降は秋予選に勝った学校だけが3月の本戦へ進みます。次の編成は翌年の新入生が全員そろった直後です。
7. 冬には地元の中学生の情報が自動で届きます。知らせにある守備位置の新入生と高ランク選手に出会いやすくなり、結果は次の入学式で分かります。3年生の技の継承、名門戦、年数制限のない運営も継続します。

入部時にA以上を引く確率は創部時10%。経過年数、公式戦の通算勝利、春夏の優勝、スカウト網への投資で上がり、30年目の強豪校では9割近くに達します。冬の地元だよりは該当ポジションに追加の抽選機会をもたらします。

選手は打撃・投球・守備に加えて長打力・制球力・走力・選球眼・球威・肩力を持ちます。練習ごとに全員が札に対応する2能力を鍛え、各自が指定した自主練習にも取り組みます。全9項目が試合評価に関わります。能力それぞれの基本上限は、C 58、B 86、A 122、S 174、SS 250、Z 無制限。育成研究室1レベルにつき +4、黄金の指導書1冊につき +1 です。過去のセーブで基本上限を超えた選手は、引き続き育成できます。

購買部では手札枠と追加の練習札を購入できます。札のレアリティはN・R・SRで、基礎練習点は順に1日2・3・4点。12練習点で対応能力が1上がり、端数は選手別・能力別に持ち越します。6施設には練習設備・スカウト網・育成研究室と、自主練習を強化する個別練習棟、合宿の特能習得を後押しする合宿寮、毎月部費を支給する後援会館があります。

試合ではスコアと局面を見て采配を選びます。形勢は「有利」「いけそう」「慎重に」「厳しい」の4段階。得点を狙う強振、投手勝負、失点を抑える守備で得失点の幅が変わります。

公式戦が終わると、勝敗を問わず全部員が実戦経験を得ます。強振は打撃・長打力、投手勝負は投球・制球力、守備固めは守備・肩力を鍛えます。何度も選んだ采配に多く配分され、延長でも1試合の経験総量は一定です。練習試合では選んだ1分野に公式戦の6分の1の経験が入ります。実戦経験は練習で積んだ経験と合算され、能力上限まで成長します。

進行はカードをめくるたび、操作するたびにブラウザに自動保存されます。旧版の記録はその場面から続けられます。設定で2校の記録を切り替え、個別に削除できます。削除には確認画面があり、最後の記録を削除すると入学式に戻ります。

練習画面では日数と成長の目安、試合では得点と局面を最も大きく表示します。札の系統は色・絵・名称を併用し、普段の練習はワンタップ、覚醒や希少な獲得には個別の演出を用意しました。UI設計の参考にしたのは、桜井政博氏の「大事なものをより大きく」です。[公式動画](https://www.youtube.com/watch?v=An29jZOqyGY)

## ローカルで遊ぶ

`index.html` をブラウザで開くか、プロジェクトのフォルダーで `python -m http.server 8000` を実行して `http://localhost:8000/` を開きます。素材を含むゲーム本体に外部サービスへの依存はありません。

## 検証

- `node --test tests/*.test.cjs` で成長上限、試合報酬、連携、継承、施設、挑戦難度などの回帰テストを実行します。
- `node tests/simulation.cjs 3000` で、3つのプレイ方針について各3,000校を12年ずつ運営し、計108,000シーズンの統計を出力します。小さい札・大きい札を優先した初年度と、名門戦で100年続けた学校も検証します。
- `node tests/deck-balance.cjs 1000` で同じ初期選手の1,000校ずつを3年間育て、12枚・16枚・16枚＋手札拡張で合宿への温存と特能習得人数を比較します。
- `python tests/browser.py` で、一時ブラウザを使って1年分の操作と自動保存を検証します。Python 3.10以降、websockets 14以降、EdgeまたはChromiumが必要です。Edge以外では環境変数 `CHROMIUM` に実行ファイルを指定します。

GitHub Pages の公開元は `main` ブランチのルートです。
