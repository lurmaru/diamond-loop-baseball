# ダイヤモンドループ

青葉高校野球部の監督となり、練習カードで選手を育て、夏の全国優勝を目指す高校野球ローグライト。登録不要で、スマホの縦画面とデスクトップに対応しています。

## 遊び方

1. 最初の春は、9人の新入生を1枚ずつ開封します。カードの縁と記号が選手ランク（C・B・A・S・SS・Z）を表し、S以上は天才です。全員が入部し、最後に重点育成する1人を選びます。
2. 練習カードは毎回引き直されます。能力の伸びと1〜3マスの歩数を見比べて選びましょう。好調マスでは重点選手が伸び、逆風マスでは用具修理が発生します。指導日・大会・年度末には必ず止まります。
3. 移動1マスごとに部費1Gを獲得。購買部では打撃・投球・守備の教材を買えます。OBの訪問では部費か講習を選べます。練習試合に勝てば、好きな練習系統を1段階強化できます。教材・講習・勝利報酬の効果は同じ系統に重なり、その年度の練習カードに適用されます。
4. 夏の大会は4試合。3回・6回・9回の攻防で采配し、同点なら延長戦へ。指導方針と選手の特殊能力を組み合わせると、チームの連携スキルが発動します。
5. 1年生は年度末に進級し、3年生は卒業します。卒業する学年から1人を選ぶと、技を次の指名選手が継承します。春の新入生は最低3人で、欠けた守備位置を補います。
6. 部費と施設・指導経験は翌年に持ち越せます。施設には試合と年度末で得る伝統Ptを使用します。全国優勝または3年目で名門戦が解放され、優勝するたびに次の難度へ進めます。プレイ年数の上限はありません。

進行はカードをめくるたび、操作するたびにブラウザに自動保存されます。旧版の記録はその場面から続けられます。設定からもう一つのチームを作り、記録を切り替えて遊べます。

## ローカルで遊ぶ

`index.html` をブラウザで開くか、プロジェクトのフォルダーで `python -m http.server 8000` を実行して `http://localhost:8000/` を開きます。素材を含むゲーム本体に外部サービスへの依存はありません。

## 検証

- `node --test tests/*.test.cjs` で成長上限、試合報酬、連携、継承、施設、挑戦難度などの回帰テストを実行します。
- `node tests/simulation.cjs 3000` で、3つのプレイ方針について各3,000校を12年ずつ運営し、計108,000シーズンの統計を出力します。
- `python tests/browser.py` で、一時ブラウザを使って1年分の操作と自動保存を検証します。Python 3.10以降、websockets 14以降、EdgeまたはChromiumが必要です。Edge以外では環境変数 `CHROMIUM` に実行ファイルを指定します。

GitHub Pages の公開元は `main` ブランチのルートです。
