# ダイヤモンドループ

青葉高校野球部の監督となり、練習カードで選手を育て、夏の全国優勝を目指す高校野球ローグライト。登録不要で、スマホの縦画面とデスクトップに対応しています。

## 遊び方

1. 春は毎回3枚の練習カードから1枚を選びます。「選手名鑑」で重点育成に指定した選手には成長ボーナスが付きます。
2. 指導方針と特殊能力を選びます。同じ方針を採用した経験は翌年以降にも蓄積します。チーム内の特殊能力を組み合わせると連携スキルが発動します。
3. 練習6回で夏の大会に入ります。3回、6回、9回の攻防で作戦を選び、同点なら延長戦へ。4試合を勝ち抜けば全国優勝です。
4. 秋冬は翌年に向けた育成期間です。卒業時に先輩の技をひとつ選び、次の指名選手に継承します。新入生候補の虹色の封筒は天才の合図です。
5. 試合と卒業で得た伝統Ptは施設の強化に使えます。全国優勝または3年目で名門戦が解放され、優勝するたびに次の難度へ進めます。プレイ年数の上限はありません。

進行は操作ごとにブラウザのローカルストレージに保存されます。効果音は右上の設定から有効にできます。

## ローカルで遊ぶ

`index.html` をブラウザで開くか、プロジェクトのフォルダーで `python -m http.server 8000` を実行して `http://localhost:8000/` を開きます。素材を含むゲーム本体に外部サービスへの依存はありません。

## 検証

- `node --test tests/engine.test.cjs` で成長上限、試合報酬、連携、継承、施設、挑戦難度などの回帰テストを実行します。
- `node tests/simulation.cjs 3000` で、3つのプレイ方針について各3,000校を12年ずつ運営し、計108,000シーズンの統計を出力します。
- `python tests/browser.py` で、一時ブラウザを使って1年分の操作と自動保存を検証します。Python 3.10以降、websockets 14以降、EdgeまたはChromiumが必要です。Edge以外では環境変数 `CHROMIUM` に実行ファイルを指定します。

GitHub Pages の公開元は `main` ブランチのルートです。
