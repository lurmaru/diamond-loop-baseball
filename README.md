# 星灯りの旅団

灯守のギルドを率いて冒険者を育て、苔むす石巨人や星喰いの竜が待つ谷へ遠征する、スマホ縦画面向けの育成RPGです。登録不要で、ブラウザに2つの旅団を自動保存できます。

[星灯りの旅団で遊ぶ](https://lurmaru.github.io/diamond-loop-baseball/)

## 最初の1年

1. 春に届く3通の契約書を開け、重点育成する1人を選びます。全員が加入し、剣士や守護騎士、星詠み、吟遊詩人など全9職がそれぞれの技を戦闘に持ち込みます。
2. 修練札で3・5・8日進み、剣技・秘術・探索を育てます。短い札は市集や祠に寄りやすく、長い札は1日あたりの経験が増えます。行事では途中で止まり、実際に進んだ日数に応じて成長します。「おまかせ修練」は最長15日。寄り道や覚醒で操作が戻ります。
3. 5月に今年の誓いを選びます。系統ごとに強化される修練と戦技が決まり、付随する祝福は毎年変わります。6月と12月の野営では、選んだ札を使って重点育成中の仲間が奥義に挑戦します。
4. 夏は玻璃の谷の3区画を攻略します。攻撃が激しいときは迎撃で星力を取り戻し、結界には星術を使えます。体力と星力を引き継ぐので、道中では回復と火力強化のどちらを取るかも重要です。撤退しても出撃した3人に実戦経験が残ります。
5. 秋の星門を突破すると、春に夜明けの星塔へ挑戦できます。夏の遠征後と翌春の新規契約後にデッキを組み替えます。所持札、札の進化、拡張した手札枠は次の年にも引き継ぎます。

## 旅団の育て方

- 出撃隊は3人。職業を3系統そろえると開始時の星力が1増え、同じ系統を2人以上並べると対応する戦技の威力が2上がります。遠征出発前に「冒険者」で編成できます。
- 剣技の奥義「連撃」は隙への追撃、秘術の「星詠術」は回復と結界の突破、探索の「罠師」は猛攻への反撃を強化します。野営では習得の基本確率が43%、直伝札なら67%。祠で石碑を選んだ場合はそれぞれ10%、21%です。
- 契約期間は3年。独立する先達のうち1人が新人に奥義を託します。先達が谷に戻ると修練札に直伝を残せます。野営でひらめいた札には永久に連携効果が加わります。
- 市集では手札枠や修練札を購入できます。星灯のランタンを補強すると、以降の遠征で最大体力が2増えます。功績を5種類の拠点施設に投資すると、経験・資質・能力上限・奥義習得・資金を長期に伸ばせます。
- 年数制限はありません。夏または春の遠征を踏破すると、拠点でより深い層を選べます。深度は開放済みの範囲で選び直せます。

## 実行・検証

依存パッケージのない静的サイトです。リポジトリ直下で `python -m http.server 8000` を実行し、ブラウザで `http://localhost:8000/` を開きます。配信先は同じファイルを置いた GitHub Pages です。

- `node --test tests/*.test.cjs` は育成、職業・予兆・戦闘報酬、世代交代、旧作の回帰テストを実行します。
- `node tests/guild-simulation.cjs 1200 10` は戦闘・遠征難度・修練方針別のシミュレーションと、100年の世代交代を実行します。
- `python tests/guild_browser.py` はテスト用ブラウザで加入から4年目まで操作し、4つの画面幅、遠征中・戦闘終了時の再読み込み、編成、施設、記録切り替えを確認します。Python の websockets と Edge、または環境変数 CHROMIUM で指定する Chromium が必要です。
